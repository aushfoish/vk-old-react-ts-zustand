# Vkontakte.ru React

Архивная первая версия точной копии интерфейса ВКонтакте начала-середины 2010-х годов с ограниченным функционалом. Перенос аналогичного проекта (https://github.com/aushfoish/vk-old-design-js) с Vanilla-JS на React-TS 

## Цель проекта

* Изучение возможностей работы с современными фреймворками и сетевыми запросами

## Реализовано:

* Кастомный MP3-плеер с загрузкой данных из облака. Добавлена возможность перемотки через полоску хронометража, динамическое обновление таймеров и загрузка метаданных через Fetch API и Promise 
* Маршрутизация через React Router Dom
* Возможность фонового воспроизведения музыки при навигации по страницам сайта
* Возможность отправлять посты на стену через REST API
* Кастомный граффический редактор на базе Canvas API. В тестовой версии добавлена настройка толщины кисти, интенсивности и очистки холста (доступен для ознакомления по ссылке: https://aushfoish.github.io/vk-old-react-ts-zustand/canvas)

## В разработке:

* Цветовая палитра и отправка изображения из графического редактора на стену через сложный алгоритм конвертации
* Авторизация на стороне клиента
* Возможность сжатия и загрузки фотографий через возможности Canvas API
* Различные QoL - улучшения


### Технологии
* React
* Typescript
* Zustand
* React Router DOM
