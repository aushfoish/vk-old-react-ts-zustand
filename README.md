# Retro VK — Мультимедийная SPA-платформа с ретро-интерфейсом

Полнофункциональное Single Page Application (SPA), воссоздающее интерфейс легендарной соцсети начала 2010-х годов. Проект успешно мигрирован с императивного подхода (Vanilla JS) на декларативную компонентную архитектуру React + TypeScript и интегрирован с облачным бэкендом.

[👉 Ссылка на живой деплой (GitHub Pages)](https://aushfoish.github.io/vk-old-react-ts-zustand)

---

## 🚀 Архитектурные решения и функционал (Key Features)

- **Real-time Лента (WebSockets):** Интерактивная стена с возможностью публикации текстовых постов и графики. Интегрирован протокол WebSockets (Native API) для мгновенного обновления контента у всех пользователей без перезагрузки страниц.
- **Сквозной Аудиоконтекст (State Management):** Кастомный мультимедийный плеер на базе HTML5 Audio API. Управление логикой треков, плейлистами, громкостью и высокочастотным обновлением хронометража полностью централизовано в Zustand Store. Музыка бесшовно воспроизводится в фоновом режиме при переходах между роутами.
- **Модуль Граффити (Canvas API):** Самописный графический редактор с динамическим изменением свойств кисти (толщина, прозрачность, палитра). Реализован алгоритм клиентской конвертации бинарных данных (`Blob` / `Base64`) для последующей публикации изображений в общую ленту.
- **BaaS & Cloud Storage (Supabase):** Спроектирована реляционная структура баз данных в PostgreSQL. Настроена интеграция с облачными хранилищами (Supabase Storage Buckets) для дистрибуции аудиофайлов и пользовательского медиаконтента.
- **Оптимизация производительности & Ресайз:** Написан алгоритм предварительного сжатия и форматирования загружаемых аватарок через скрытый Canvas-контекст на клиенте ради экономии серверного пространства. Оптимизированы рендеры компонентов при обновлении таймеров плеера.
- **Клиентская Авторизация:** Механизм персистентности сессии на базе `localStorage` с динамическим восстановлением стейта пользователя при инициализации приложения, сквозным виджетом профиля в хэдере и логикой безопасного логаута.
- **UI/UX & Валидация:** Адаптивная кроссбраузерная верстка на с использованием SCSS Modules. Реализована строгая валидация пользовательского ввода (ограничение длины строк, предотвращение отправки пустых сабмитов и защита от загрузки посторонних файлов).
- **Отказоустойчивость интерфейса (Error Handling):** Реализована обработка критических ошибок сети при интеграции с Supabase. При падении сетевых запросов приложение не "падает", а перехватывает исключения в блоках try/catch, отображая интерактивные плашки уведомлений с возможностью ручной инициации повторных запросов (refetch).
- **Культура коммитов (CI/CD):** Настроены pre-commit хуки через Husky и lint-staged. Код автоматически проходит проверку линтером перед каждым коммитом, что исключает попадание синтаксических ошибок в удаленный репозиторий.
- **Файловая структура проекта:** Структура файлов и блоки кода разделены на логические переиспользуемые модули и утилиты согласно методологии FSD.

## 🛠 Технологический стек (Tech Stack)

- **Core:** React 19, TypeScript, Vite.
- **State & Routing:** Zustand, React Router DOM.
- **Backend & API:** Supabase (PostgreSQL), Tanstack Query, WebSockets (Native Protocol).
- **Browser API:** HTML5 Canvas API, HTML5 Audio API, LocalStorage.
- **Styles & DevTools:** SCSS Modules, Git/GitHub (GitHub Pages).
- **CI/CD & Quality Control:** Husky, lint-staged, ESLint
- **Testing:** Vitest


## 🐳 Развертывание и запуск в Docker (Production)

### 📋 Предварительные требования:
Наличие установленного Docker Desktop на вашем ПК **[Docker Desktop](https://docker.com)**.

### 🛠️ Инструкция по развертыванию:

1. **Клонирование репозитория на ваш компьютер:**
   ```bash
   git clone https://github.com/aushfoish/vk-old-react-ts-zustand
   ```
2. **Переход в директорию проекта:**
   ```bash
   cd vk-old-react-ts-zustand
   ```
3. **Сборка Docker-образа:**
   ```bash
   docker build -t vk-react-ts .
   ```
4. **Запуск контейнера в фоновом режиме:**
   ```bash
   docker run -d -p 8080:80 vk-react-ts
   ```

После успешного запуска приложение будет доступно по адресу: **http://localhost:8080**
